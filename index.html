Dimensionless axial force n = N / (b h fc) and moment m = M / (b h² fc). Failure envelope m = 0.5n − (2/3)n² up to n = 0.75 for the elastic stage II, and m = 0.5n − (β/α)n² up to n = 2β/α for the concrete stage III, symmetric about m = 0. The load path from p1 through p2 is extended to its intersection p3 with that envelope; LF is how far along the permanent-to-live path the section gets before it is reached. Mirrors MN_cap.m.
